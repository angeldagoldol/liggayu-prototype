SCOREDESK
Student Score Management System Using Arrays
HTML + CSS + JavaScript + Java

1. Extract the ZIP. Do not run the files from inside the ZIP viewer.
2. Install a full Java Development Kit: JDK 17 or newer.
   Check in a terminal: java -version
                        javac -version
3. On Windows, double-click run.bat.
   On macOS/Linux, open a terminal in this folder and enter: sh run.sh
4. Leave that terminal open and open this address in a browser:
   http://localhost:8080
5. Click Load sample data, or enter a student name and three scores.
   Scores must be 0 to 100. Up to two decimal places are accepted.
6. Use Print report to print or save the report through your browser.

IMPORTANT
The Java server must run on a laptop/desktop. This ZIP is a local project,
not an already hosted website. Opening index.html directly does not run Java.

Refreshing the page keeps records while Java is running.
Stopping/restarting Java, or choosing Reset all, clears every record.
There is no database, file saving, login, or permanent student storage.

PORT ALREADY IN USE?
