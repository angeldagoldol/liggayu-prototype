SCOREDESK — RENDER + GMAIL EDITION
HTML + CSS + JavaScript + Java

This is a deployment-ready source package, NOT a live website.

DEPLOY ONLINE
1. Extract the ZIP; open its student-score-system folder.
2. Use a separate GitHub repository for ScoreDesk.
3. Put Dockerfile, render.yaml, src/, web/ and tests/ at the repository root.
4. Follow DEPLOY_RENDER.md to create a Render Docker Web Service on the Free plan.
5. Wait for Render to show Live, then open the service's assigned website address.
6. Click Share via Gmail, add a recipient, review the email, then Send.
   Copy link is also available. No email is sent automatically.

RUN LOCALLY
Install a full JDK 17 or newer.
Windows: double-click run.bat
macOS/Linux: run sh run.sh
Open http://localhost:8080 and keep Java running.
Local sharing is intentionally disabled: localhost links are not public websites.

IMPORTANT
The public prototype has no login. All visitors share the same temporary records.
Only use fictional student names and scores.
Restarting, redeploying, idle shutdown or Reset all clears the arrays.
A Gmail link is not a saved report. Print the report when you need a copy.
There is no database or permanent saving.
